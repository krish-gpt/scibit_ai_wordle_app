# **App Name**: SciBit

## Core Features:

- Daily Word Generation: Daily AI-related term generation based on difficulty using a AI tool.
- Clue Generation: Clue generation for the AI term of the day. Powered by an AI tool.
- Guess Input and Feedback: Wordle-style input and feedback mechanism (green, yellow, gray tiles).
- Social Sharing: Social media sharing of results, including number of attempts and feedback pattern.
- Ad Display: Display ads after game completion for monetization (AdSense integration).
- Term Summary: Provide a summary of the AI term and its meaning at the end of the game, using an AI tool.

## Style Guidelines:

- Primary color: Deep sky blue (#007BFF) for a modern and technical feel.
- Secondary color: Light gray (#F8F9FA) for backgrounds and neutral elements.
- Accent color: Yellow-Green (#9ACD32) to indicate when characters match. This brings to mind code editors, and is visible on computer screens.
- Clean and readable sans-serif font for clear presentation of words and clues.
- Simple and AI-related icons (neural network, robot, etc.) for visual appeal.
- Responsive design to ensure playability on mobile and desktop devices.
- Subtle animations for feedback (tile flipping, word reveal) to enhance user experience.
